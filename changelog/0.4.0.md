# 0.4.0

## 亮点

- **替你点掉 ChatGPT 的授权卡**：往 Drive 写文件这类操作前，ChatGPT 会停下问「允许 ChatGPT 使用 Google Drive 吗？」。默认 voyager 以退出码 3 停下并给出对话链接；加 `--approve-apps always` 由插件点「始终允许」，`--approve-apps once` 点「允许一次」。需要 Voyager 2.2.0 或更高版本。
- **长任务按时收尾**：Pro 的一轮回答大约 80 分钟后会被打断，什么都交不出来。`voyager ask --timebox 70` 让它到 70 分钟时收尾，把做完和没做完的分开，打成一个 ZIP 交回来。

## 其他

- 新增 `contrib/web-pro-kit/`（社区贡献，不进 npm 包）：把仓库长期镜像到 Google Drive、任务中途追加需求、等待交付标记的一组 Python 脚本。上传前会给密钥、邮箱和本机用户名打码，认不出的文件不上传并列出来。
- 没配 rclone 但装了 Google Drive 桌面版时，agent skill 会提议改用本地的 Drive 文件夹传文件。
- 依赖的 `@voyager-crew/bridge-protocol` 升到 0.4.0。
